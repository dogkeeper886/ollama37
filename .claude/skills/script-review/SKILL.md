# Script Review

Audit a video or presentation script as spoken narration. Use `/script-review` to run.

## When to use
- After writing a YouTube video script or demo script
- Before recording — catch delivery issues while editing is cheap
- When a script reads fine on paper but would sound off spoken aloud

## What this reviews

| Dimension | Question |
|-----------|----------|
| **Hook** | Will viewers stay past the first 10 seconds? |
| **Numbers** | Can a listener absorb the numbers, or will they blur? |
| **Transitions** | Does each section lead into the next? |
| **Language** | Does every sentence sound natural spoken aloud? |
| **Screen sync** | Do screen directions match what the narrator is saying? |
| **Pacing** | Is the weight distributed well across sections? |

## What this does NOT review
- Technical accuracy of benchmark data
- Grammar or spelling (it's a spoken script, not a doc)
- Video editing or production quality
